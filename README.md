# Burger Must Selection

Sistema de gestión para hamburguesería. Incluye menú digital, tienda online con MercadoPago, panel de administración y pantalla de cocina en tiempo real.

## Stack

- **Frontend:** React 18 + Vite
- **Deploy:** Vercel
- **Pagos:** MercadoPago (próximamente)
- **Backend:** Node.js + Express (próximamente)
- **DB:** PostgreSQL via Supabase (próximamente)

## Roles

| Rol | Vistas disponibles |
|---|---|
| Cliente | Menú digital, Tienda online |
| Administrador | Todo + Panel admin + Finanzas |
| Cocina | Pantalla de pedidos en tiempo real |

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy

El proyecto se despliega automáticamente en Vercel al hacer push a `main`.
